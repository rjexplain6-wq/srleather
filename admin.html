🔑

ImgBB API Key (ছবি আপলোড এপিআই)

প্রোডাক্ট, ব্যানার ও ক্যাটাগরির ছবি সরাসরি ক্লাউডে আপলোড করার জন্য এই কি প্রয়োজন।

🟢 বর্তমান কি সক্রিয়

কীভাবে ফ্রিতে আপনার নিজস্ব ImgBB API কি পাবেন?

  1. ব্রাউজারে api.imgbb.com লিংকে যান।
  2. একটি ফ্রি একাউন্ট তৈরি করুন অথবা সাইন ইন করুন।
  3. সেখানে 'Get API key' বাটনে ক্লিক করে ৩২ অক্ষরের কি-টি কপি করুন।
  4. উপরের বক্সে পেস্ট করে '💾 কি সেভ করুন' বাটনে চাপুন। এটি আজীবনের জন্য কাজ করবে!

শোরুম লোকেশন প্রদর্শন নীতি (Showroom Visibility)

💡 স্মার্ট হাইডিং নিয়ম: আপনি যদি নিচে শোরুমের ঠিকানা বা যোগাযোগের তথ্য খালি রাখেন, তবে কাস্টমারদের ওয়েবসাইটে কোনো খালি বক্স বা শোরুমের ঠিকানা দেখানো হবে না।
